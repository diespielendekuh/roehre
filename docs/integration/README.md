# Einbau je Spielprojekt

Je Spiel eine Datei `<projekt>.md`: wie roehre dort eingebaut ist, welche Einstellungen und
Voreinstellungen das Spiel nutzt, welche Besonderheiten es hat (Auflösung, Pixel-
Seitenverhältnis, Renderer, Menü, HDR) und welche Wünsche offen sind. Wer roehre ändert, sieht
hier, welche Spiele betroffen sein können.
